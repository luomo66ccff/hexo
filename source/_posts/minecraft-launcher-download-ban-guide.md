10 月 20 日那天，不少人打开 PCL 想装个新版本，结果发现「下载」页没了；过了几个小时，PCL-CE 和 HMCL 的开发版也跟着更新，在中国大陆把游戏下载关掉了。群里一下子炸锅：「我是不是玩不了 MC 了？」「存档还在吗？」「网上那个解锁版能用吗？」

先把心放回肚子里：**已经装好的游戏照样能玩，存档也不会消失。** 受影响的是「用第三方启动器下载 / 安装游戏本体」这一步。这篇教程按你现在的处境分开讲，每种情况都给出能直接照做的步骤。

> 信息核对截至 **2026-10-21**。启动器的版本号、发布时间和改动内容都以各项目在 GitHub 上的官方发布页为准；事情还在变化，文末附了来源，遇到和本文不一样的情况，以官方最新公告为准。

HMCL 稳定版目前还没受影响，但开发版已经加上了限制，**之后发布的稳定版大概率也会带上**，所以 HMCL 用户也请按情况 B 提前准备。

### 怎么查版本

- **PCL / PCL-CE**：打开启动器 → 顶部「更多」→「关于与鸣谢」，就能看到版本号（不同版本菜单名可能略有差别）。如果不敢打开（原因见情况 B），可以右键启动器的 `.exe` →「属性」→「详细信息」，看「文件版本」。
- **HMCL**：打开后在「设置」→「通用」里能看到当前版本；也可以直接看文件名，比如 `HMCL-3.16.4.exe`。

## 动手前先记住三件事

### 1. 只从官方渠道下载启动器

出事之后最容易出事的，不是游戏，是电脑。已经有人仿冒 HMCL 官网分发带木马的安装包，被点名的仿冒站包括 `hmcl.io` 和 `hmcl.app`。网上流传的「PCL 解锁版」「去限制版」「绿色修改版」，来路一律不明，**别下、别运行、也别转发到群里**。

本文用到的地址都放在[文末的官方地址清单](#official-links)里，下载时对着清单核一遍网址。

<a id="backup"></a>

### 2. 先备份存档

存档就是你的心血，先复制一份到别处，后面怎么折腾都不慌：

1. 找到你的 `.minecraft` 文件夹。PCL / HMCL 默认放在**启动器所在文件夹**里；官方启动器在 `%APPDATA%\.minecraft`（按 `Win + R`，粘贴这一串，回车就能打开）。
2. 存档在 `saves` 里。如果你在 PCL 里开过「版本隔离」，存档会在 `.minecraft\versions\版本名\saves` 里。
3. 把整个 `saves` 文件夹（或者干脆整个 `.minecraft`）复制到 U 盘、网盘或者另一个磁盘。

### 3. 不建议改系统地区去「绕过」

PCL-CE 和 HMCL 是通过 Windows 的地区、语言、时区和网络位置来判断你在哪的。改这些设置会影响系统里别的软件，开发者也随时可能调整检测方式，折腾半天可能白干，还可能违反相关规定。本教程不教这一步，下面讲的都是正规路线。

## 情况 A：还没有启动器（全新萌新）

<a id="official-launcher"></a>

### 路线 1（推荐）：官方 Minecraft Launcher

这是 Mojang 自己的启动器，不受这次事件影响。**前提：你需要一个买过 Minecraft Java 版的微软账号**；没买的话只能玩试玩版。

1. 打开 Minecraft 官网下载页 `https://www.minecraft.net/zh-hans/download`，选择 Windows 版下载。也可以直接用官方安装包地址 `https://launcher.mojang.com/download/MinecraftInstaller.msi`。
2. 双击 `MinecraftInstaller.msi`，一路「下一步」装好。
3. 打开「Minecraft Launcher」，点「登录」，用你的**微软账号**登录。
4. 左侧选「Minecraft: Java Edition」。
5. 想玩最新正式版：直接点绿色的「游玩」。想玩旧版本：点上方「配置」→「新配置」→ 在「版本」里选你要的版本 → 保存，再回到「游戏」页从左下角选这个配置后点「游玩」。
6. 第一次会下载游戏文件，国内网络可能比较慢，**挂着别关**，下完以后就不用再下了。

> 官方启动器只负责原版游戏。想装 Fabric、Forge 这类模组加载器，需要到它们各自的官网下载安装器，装好后会自动出现在官方启动器的版本列表里。对萌新来说，先把原版玩起来就好。

### 路线 2：没买正版，想免费玩——网易《我的世界》中国版

中国版由网易运营，在官网 `https://mc.163.com/` 下载，免费，需要实名注册。它有自己的启动器和账号体系，和国际版（微软账号）**不互通**：国际版的存档、皮肤、好友不能直接带过去，服务器也是分开的。

适合：只想和同学一起玩、不打算买国际版、主要玩网易服务器的同学。

### 路线 3（进阶）：开源启动器 Prism Launcher

已经买了正版、又想要第三方启动器那种「多版本、一键装模组」的体验，可以试试 Prism Launcher。它是国外的开源启动器，没有地区限制。

1. 到 `https://prismlauncher.org/download/` 下载 Windows 版安装包并安装。
2. 第一次打开会让你选语言（选「简体中文」）和 Java，按向导默认设置即可。
3. 右上角「账户」→「管理账户」→「添加微软账户」，按提示在浏览器里登录。
4. 左上角「添加实例」→ 选游戏版本，需要模组的话在右侧选加载器 → 确定。
5. 选中实例，点「启动」。

> Prism 从 Mojang 官方服务器下载游戏，国内速度可能慢一些，耐心等它下完即可。

## 情况 B：有启动器，但还没更新

这是最该抢时间的一种情况：**你手里的旧版本还能下载游戏，只要别让它自动升级。**

### PCL（龙腾猫跃原版）

PCL 的「启动器更新」默认是「在有新版本时自动下载」，所以**联网状态下直接打开，很可能被自动升级到 2.99.0.0**。正确顺序是先断网再打开：

1. **断网**：拔掉网线，或者点任务栏右下角的网络图标，把 Wi-Fi 关掉。
2. 打开 PCL。
3. 进入「设置」→ 左侧「其他」，在「启动器」这一栏找到「启动器更新」，改成「**关闭更新提示**」。
4. 关掉 PCL，**重新联网**，再打开 PCL，确认「更多」→「关于与鸣谢」里的版本号还是原来的。

如果不想打开 PCL，也可以改配置文件：

1. 关闭 PCL（任务栏里也不要留着）。
2. 进入 PCL 所在文件夹里的 `PCL` 子文件夹，用记事本打开 `Setup.ini`。
3. 找到以 `SystemSystemUpdate:` 开头的那一行，把冒号后面的数字改成 `3`；没有这一行就在末尾新起一行，写上：

```ini
SystemSystemUpdate:3
```

4. 保存。注意冒号是**英文冒号**。

已经弹出了更新窗口？**不要点「更新」**。在任务栏的 PCL 图标上右键 → 关闭窗口，然后按上面的步骤关掉自动更新。如果重新打开后发现版本已经变成 2.99.0.0，就去看[情况 C](#case-c)。

### PCL-CE（社区版）

PCL-CE 默认也是「自动下载新版本并提示」。和原版一样：

1. 先断网，再打开 PCL-CE。
2. 在「设置」里找到启动器更新相关选项，从「自动下载」改成**只提示**或**关闭**。
3. 重新联网。以后再看到 2.15.1 的更新提示，不要点更新。

### HMCL

HMCL 不会自己偷偷完成升级，更新需要你手动点。所以只要做到两点：

1. 「设置」→「通用」里，把更新通道设为「**稳定版**」，不要用开发版。
2. 以后看到更新提示，先确认新版本有没有加上地区限制（可以回来看看这篇的更新记录），**不确定就先别点**。

### 趁现在，把想玩的版本都装好

只要旧版本还能下载，就把以后可能要玩的东西一次性备齐：

- 最新正式版，以及你和朋友常玩的版本；
- 需要的 Fabric / Forge / NeoForge 等加载器；
- 常玩的整合包。

装完后**每个版本都启动进一次主菜单**，确认文件下载完整。PCL-CE 2.15.1 只允许启动「本地文件已经完整」的版本，缺文件时不会帮你补全，现在多跑一次，以后少踩坑。

<a id="case-c"></a>

## 情况 C：不小心更新到了禁下载版本

先别急着卸载。**已经装好的版本还能启动，存档也都在。** 你有两条路：回退到官方旧版，或者换到官方启动器。

> 回退只能解决眼前的问题：旧版本可能随时被开发者停用，下载源也可能变化。长期来看，路线 2 更稳。

### 路线 1：回退到官方发布的旧版本

下面每一个旧版本都来自启动器作者自己的 GitHub 仓库。回退时**只替换启动器的 `.exe`**，不要动 `.minecraft` 和 `PCL` 文件夹，你的设置和游戏都会保留。动手前请先[备份存档](#backup)。

**PCL（回退到 2.13.1.1）**

1. 打开 PCL 官方仓库的 2.14.0.0 标签页面：`https://github.com/Meloong-Git/PCL/tree/2.14.0.0`。
2. 在文件列表里点「最新正式版.zip」，再点右侧的下载按钮（Download raw file）。这个压缩包里是 **2.13.1.1** 正式版，本文已下载核对过文件版本。
3. 关闭正在运行的 PCL，然后**断网**。
4. 解压压缩包，用里面的 `Plain Craft Launcher 2.exe` 替换你原来的启动器文件（建议先把旧的 2.99 改个名留着，而不是直接删）。
5. 打开 PCL，**马上**按情况 B 把「启动器更新」改成「关闭更新提示」。
6. 重新联网，确认「更多」→「关于与鸣谢」里的版本号是 2.13.1.1。

**PCL-CE（回退到 2.15.0）**

1. 打开 `https://github.com/PCL-Community/PCL-CE/releases/tag/v2.15.0`。
2. 在下方「Assets」里下载 `PCL2_CE_Release_x64.exe`（大多数电脑选这个；骁龙等 ARM 电脑选 `ARM64`）。
3. 关闭 PCL-CE，断网，用新下载的文件替换原来的 `.exe`。
4. 打开后先关掉自动更新，再联网。

**HMCL（回到稳定版 3.16.4）**

1. 打开 `https://github.com/HMCL-dev/HMCL/releases/tag/v3.16.4`，下载 `HMCL-3.16.4.exe`；也可以去 HMCL 官网 `https://hmcl.huangyuhui.net/download/` 下载稳定版。
2. 关闭 HMCL，用新文件替换旧的 `.exe`（或者直接放在同一个文件夹里运行新的）。
3. 打开后到「设置」→「通用」，把更新通道设为「稳定版」。

### 路线 2：换到官方启动器，把存档搬过去

1. 按[情况 A 的路线 1](#official-launcher)装好官方启动器，登录，并把你要玩的版本先启动一次，让它把游戏下载好。
2. 打开你原来启动器的存档文件夹（`.minecraft\saves`，开过版本隔离的在 `.minecraft\versions\版本名\saves`）。
3. 把里面的**存档文件夹**整个复制到 `%APPDATA%\.minecraft\saves`。
4. 打开官方启动器，选**相同或更高**的版本进入游戏，单人游戏列表里就能看到你的存档。

> 存档能从低版本升到高版本，但不建议反过来降版本打开，可能会坏档。第一次在新版本打开老存档前，确认已经备份过。

## 常见问题

**Q：PCL 2.99 是不是不能用了？**
不是。它只是删掉了下载游戏的功能，已经装好的版本照样能启动。

**Q：网上说是因为某某举报 / 某某公司施压，是真的吗？**
PCL 作者在 2.99.0.0 的发布说明里只说是为了遵守相关法律法规，并表示和网易、微软无关；其他具体说法都没有官方证实。网上流传的「通知截图」也有人指出是伪造的，看到了别急着转。

**Q：什么时候能恢复？**
没人知道。想第一时间知道，就关注各启动器的 GitHub 发布页和官方公告，而不是来路不明的群消息。

**Q：我已经下了一个「解锁版 PCL」，怎么办？**
先别运行。如果已经运行过，用杀毒软件全盘扫描，并及时修改常用账号（尤其是微软账号）的密码。
