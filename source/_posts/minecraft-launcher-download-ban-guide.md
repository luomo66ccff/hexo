10 月 20 号下午，群里突然有人问：PCL 的下载页怎么没了？

一开始大家还以为是 bug，后来才发现 PCL 直接发了 2.99.0.0，把下载游戏的功能整个删了。当天晚上 PCL-CE 发了 2.15.1，HMCL 的开发版也跟着更新，两边都在中国大陆关掉了游戏下载。

不用慌，已经装好的游戏还能正常启动，存档也一个都不会少。这次动的只是「用第三方启动器下载、安装游戏本体」这一步。下面按你现在的情况分开说，挑自己那段看就行。

> 文中的版本号和日期都对照过各启动器在 GitHub 上的发布页，截至 2026-10-21。事情还在变，如果你看到的和这里写的不一样，以官方最新公告为准。

HMCL 的稳定版暂时没动，但开发版已经加了限制，下一个稳定版多半也会带上。用 HMCL 的话，最好也照着「还没更新」那一节先准备好。

### 怎么查版本

- PCL / PCL-CE：打开启动器，点顶部「更多」→「关于与鸣谢」就能看到（不同版本的菜单名可能有点出入）。怕一打开就被自动更新（原因后面会说），也可以不打开，右键启动器的 `.exe` →「属性」→「详细信息」，看「文件版本」。
- HMCL：「设置」→「通用」里有当前版本，或者直接看文件名，比如 `HMCL-3.16.4.exe`。

## 动手之前

### 1. 启动器只认官方渠道

这种时候，比玩不了游戏更麻烦的是电脑中毒。已经有人仿冒 HMCL 官网发带木马的安装包了，被点名的有 `hmcl.io` 和 `hmcl.app`。还有群里传的「PCL 解锁版」「去限制版」「绿色修改版」，不知道是谁改的，也不知道改了什么，别下，别开，也别往群里转。

文中用到的地址我都放在了[文末](#official-links)，下载前对一下网址。

<a id="backup"></a>

### 2. 先把存档备份一份

后面不管换版本还是换启动器，有备份心里就踏实：

1. 找到 `.minecraft` 文件夹。PCL 和 HMCL 默认把它放在启动器所在的文件夹里；官方启动器的在 `%APPDATA%\.minecraft`，按 `Win + R`，把这串粘进去回车就能打开。
2. 存档在 `saves` 里。PCL 开了「版本隔离」的话，存档在 `.minecraft\versions\版本名\saves`。
3. 把 `saves` 整个复制到 U 盘、网盘或者别的盘。嫌麻烦就直接复制整个 `.minecraft`。

### 3. 别去改系统地区

PCL-CE 和 HMCL 是看 Windows 的地区、语言、时区和网络位置来判断你在哪的。改这些会连带影响电脑上别的软件，开发者也随时可能换检测方式，改了不一定有用，还可能违反相关规定。这篇不讲这个，下面说的都是正常能走的路。

## 还没装启动器

<a id="official-launcher"></a>

### 官方 Minecraft Launcher（最推荐）

Mojang 自己的启动器，这次的事和它没关系。需要一个买过 Java 版的微软账号，没买的话只能玩试玩版。

1. 打开官网下载页 `https://www.minecraft.net/zh-hans/download`，下载 Windows 版。也可以直接下安装包：`https://launcher.mojang.com/download/MinecraftInstaller.msi`。
2. 双击 `MinecraftInstaller.msi`，一路「下一步」。
3. 打开 Minecraft Launcher，用微软账号登录。
4. 左边选「Minecraft: Java Edition」。
5. 玩最新版直接点「游玩」。想玩旧版本就点上面的「配置」→「新配置」，在「版本」里选好、保存，回到「游戏」页在左下角选这个配置，再点「游玩」。
6. 第一次要下载游戏文件，国内可能会慢，挂着等它下完就好，只用下这一次。

官方启动器只管原版。想玩模组的话，Fabric、Forge 这些加载器要去它们的官网下安装器，装完会自己出现在官方启动器的版本列表里。不过先把原版跑起来再说。

### 网易《我的世界》中国版（不想买正版）

网易代理的版本，官网 `https://mc.163.com/` 下载，免费玩，要实名。它的启动器和账号都是自己一套，和国际版不通，存档、皮肤、好友带不过去，服务器也是分开的。

如果你主要是跟同学一起玩、也没打算买国际版，选它就挺合适。

### Prism Launcher（买了正版，还想用第三方启动器）

用惯了 PCL、HMCL 那种多版本管理、一键装模组，可以试试 Prism Launcher。国外的开源启动器，没有地区限制。

1. 在 `https://prismlauncher.org/download/` 下载 Windows 安装包，装好。
2. 第一次打开会让你选语言和 Java，语言选简体中文，其他按默认走。
3. 右上角「账户」→「管理账户」→「添加微软账户」，跟着提示在浏览器里登录。
4. 左上角「添加实例」，选游戏版本；要装模组就在右边顺手选上加载器，然后确定。
5. 选中实例，点「启动」。

Prism 是从 Mojang 官方服务器下游戏，国内速度一般，耐心等等。

## 装了启动器，还没更新

这种情况最该赶紧动手：你手上的旧版还能下游戏，只要别让它自己升级就行。

### PCL（龙腾猫跃原版）

PCL 的「启动器更新」默认是「在有新版本时自动下载」。联着网直接打开，很可能就被升到 2.99.0.0 了。所以顺序是先断网再打开：

1. 断网：拔网线，或者点右下角的网络图标把 Wi-Fi 关掉。
2. 打开 PCL。
3. 「设置」→ 左侧「其他」，在「启动器」那一栏把「启动器更新」改成「关闭更新提示」。
4. 关掉 PCL，连上网再打开，去「更多」→「关于与鸣谢」看一眼，版本号没变就对了。

不想打开 PCL 也行，直接改配置文件：

1. 先把 PCL 关掉，任务栏里也别留着。
2. 进 PCL 所在文件夹下的 `PCL` 子文件夹，用记事本打开 `Setup.ini`。
3. 找到 `SystemSystemUpdate:` 开头的那行，把冒号后面的数字改成 `3`。没有这行就在最后加一行：

```ini
SystemSystemUpdate:3
```

4. 保存。冒号要用英文的。

如果更新窗口已经弹出来了，别点「更新」，在任务栏的 PCL 图标上右键关掉，再按上面的方法关更新。重新打开发现已经是 2.99.0.0 了，那就直接看[下一节](#case-c)。

### PCL-CE（社区版）

PCL-CE 默认也会自动下载新版本，做法和原版差不多：

1. 断网，打开 PCL-CE。
2. 在「设置」里找到启动器更新的选项，把自动下载改成只提示或者关闭。
3. 连上网。之后再提示 2.15.1，别点。

### HMCL

HMCL 不会自己偷偷升级，得你手动点才会更新，所以注意两件事就够了：

1. 「设置」→「通用」里把更新通道设成「稳定版」，别用开发版。
2. 以后再看到更新提示，先确认新版本有没有加地区限制，拿不准就先不点。这篇文章有新情况也会更新。

### 趁现在把要玩的版本都装上

旧版还能下的时候，把以后可能用到的一次装齐：

- 最新正式版，还有你和朋友常玩的几个版本；
- 要用的 Fabric、Forge、NeoForge 之类的加载器；
- 常玩的整合包。

装完每个版本都进一次主菜单，确认文件是完整的。PCL-CE 2.15.1 在国内只让启动文件齐全的版本，缺了文件不会帮你补，现在多跑一遍，后面能省不少事。

## 已经更新了

先别卸载。装好的版本还能启动，存档也都在。接下来有两条路：换回官方的旧版本，或者干脆换成官方启动器。

换回旧版只是救急，旧版本说不定哪天就被停用，下载源也可能有变化。想图个长久安稳，还是换官方启动器更省心。

### 换回官方旧版

下面的旧版本都是从启动器作者自己的 GitHub 仓库下的。换的时候只换启动器的 `.exe`，`.minecraft` 和 `PCL` 文件夹都别动，设置和游戏都会留着。换之前记得先[备份存档](#backup)。

**PCL：换回 2.13.1.1**

1. 打开 PCL 官方仓库的 2.14.0.0 标签：`https://github.com/Meloong-Git/PCL/tree/2.14.0.0`。
2. 在文件列表里点「最新正式版.zip」，再点右边的下载按钮（Download raw file）。别看标签叫 2.14.0.0，压缩包里其实是 2.13.1.1 正式版，我下下来看过文件版本。
3. 关掉正在运行的 PCL，断网。
4. 解压，用里面的 `Plain Craft Launcher 2.exe` 替换原来的启动器。旧的 2.99 可以先改个名留着，别急着删。
5. 打开 PCL，第一件事就是按上一节把「启动器更新」改成「关闭更新提示」。
6. 连上网，在「更多」→「关于与鸣谢」确认版本是 2.13.1.1。

**PCL-CE：换回 2.15.0**

1. 打开 `https://github.com/PCL-Community/PCL-CE/releases/tag/v2.15.0`。
2. 在下面的「Assets」里下载 `PCL2_CE_Release_x64.exe`。一般电脑都选这个，骁龙这类 ARM 电脑选 `ARM64`。
3. 关掉 PCL-CE，断网，用新下的文件替换原来的 `.exe`。
4. 打开后先关自动更新，再连网。

**HMCL：换回稳定版 3.16.4**

1. 在 `https://github.com/HMCL-dev/HMCL/releases/tag/v3.16.4` 下载 `HMCL-3.16.4.exe`，或者去官网 `https://hmcl.huangyuhui.net/download/` 下稳定版。
2. 关掉 HMCL，用新文件替换旧的 `.exe`，或者放在同一个文件夹里直接运行新的。
3. 打开后到「设置」→「通用」，更新通道选「稳定版」。

### 换成官方启动器，把存档搬过去

1. 照[前面的步骤](#official-launcher)装好官方启动器，登录，把要玩的版本启动一次，让它把游戏下完。
2. 打开原来启动器的存档文件夹：`.minecraft\saves`，开了版本隔离的在 `.minecraft\versions\版本名\saves`。
3. 把里面的存档文件夹整个复制到 `%APPDATA%\.minecraft\saves`。
4. 在官方启动器里选同一个版本或者更高的版本进游戏，单人游戏列表里就能看到了。

存档往高版本升没问题，反过来用低版本打开高版本的存档容易坏档。第一次用新版本打开老存档之前，确认备份还在。

## 一些常见的疑问

**PCL 2.99 是不是彻底不能用了？**

不是。它只是没了下载功能，装好的版本照样能启动。

**网上说是谁举报了、哪家公司施压，靠谱吗？**

PCL 作者在 2.99.0.0 的发布说明里只说是为了遵守相关法律法规，还特意说了和网易、微软没关系。其他说法都没有官方证实，网上传的「通知截图」也有人指出是假的，看看就好，别急着转。

**什么时候能恢复？**

谁也说不准。想第一时间知道，就盯着各启动器的 GitHub 发布页和官方公告，群里的小道消息别太当真。

**已经下了一个「解锁版 PCL」怎么办？**

还没打开的话就别打开了，直接删掉。已经运行过的，用杀毒软件全盘扫一遍，再把常用账号的密码改一下，尤其是微软账号。
