# 横幅图片署名

署名数据统一维护在 `source/_data/image_credits.json`。只有使用他人作品时显示角落署名，并收录于 `/image-credits/`；博主自己生成或原创的图片不显示署名，也不收录于来源页。

新增或更换横幅时，他人作品在 `images` 中记录图片路径、作者、原作链接和使用位置；博主自制图片只将路径加入内部 `owned_images` 列表。未知信息如实留空并说明，不把图片搜索里的相似作品或转载者当作原作者。运行 `pnpm run build` 会检查他人作品署名、自制图片不被误标注，以及所有横幅的记录覆盖情况。
